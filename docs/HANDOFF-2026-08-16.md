## 1. Qué es

**Sentinel Invest** — plataforma web argentina de control de inversiones (estilo IOL, solo lectura + agente IA). El inversor conecta su cuenta de InvertirOnline y ve cartera, cotizaciones, reportes mensuales, análisis de acciones — y tiene un **agente conversacional IA** (chat en la app + **MCP** para agentes externos).

**Stack**: server Node+TS+Express 5+Drizzle+Postgres (Docker `invertir-postgres`, puerto 5433, db `invertir` user `invertir`) · client Vite+React 18+TS+Tailwind v4+shadcn (radix-ui unificado)+recharts+tw-animate-css.

## 3. Arquitectura (server/src)

- **`services/iol/`** — provider pattern: `IolProvider` (interfaz) → `IolApiProvider` (IOL privada v2), `BymaDataProvider` (BYMA, sin nombres en panel v2 → catálogo `instrumentNames.ts`), `MockIolProvider` (datos sintéticos), `QuoteFallbackProvider` (auto: IOL→BYMA si 0/vacío). `getIolCredentials(userId)` desencripta credenciales. `portfolioMath.ts` (gainLossPct etc).
- **`services/reports/reportBuilder.ts`** — reportes mensuales reales: snapshots diarios (se guardan en GET /api/portfolio, idempotente por día), TWR Dietz, benchmark ^MERV + USDARS vía Yahoo (cache 30min→ahora 15min compartido). 4+ tablas en DB (portfolio_snapshots, ai_chat_sessions/messages, api_keys, agent_actions).
- **`services/market/`** — motor de análisis (SDD stock-analysis): `yahoo.ts` (chart API + quoteSummary con **crumb flow**: fc.yahoo.com cookie → /v1/test/getcrumb → query1.../quoteSummary; cache 15min/60min, backoff 429, envelope nunca-lanza), `indicators.ts` (RSI-14 Wilder, MACD 12-26-9, SMA 20/50/200, volumen, 52w), `signal.ts` (pesos 30/25/20/15/10, ≥60 bullish ≤40 bearish), `analyze.ts` (analyzeStock único engine). Consumidores: ruta `/api/analysis/:symbol`, tool `analyze_stock`, página `/analysis/:symbol`.
- **`services/agent/`** — motor IA: `tools/` (ToolDefinition: get_portfolio, get_quote, search_instruments, get_dollar_rates, get_monthly_reports, search_knowledge, analyze_stock, place_order STUB exclude), `registry.ts` (permisos allow/ask/exclude), `executor.ts` (7 gates: permiso→cuenta→creds→zod→timeout 15s→sanitize anti-injection→audit agent_actions), `chatLoop.ts` (OpenRouter SDK openai, 8 iteraciones, SSE tipado delta/tool_call/tool_start/tool_end/done/error, sessiones Postgres, **SYSTEM_PROMPT experto bolsa** con reglas de uso de tools), `knowledge/` (RAG sin embeddings: corpus 16 docs mercado argentino + search.ts scoring español).
- **`mcp/`** — MCP server: factory comparte las MISMAS tools del registry (zod4 adapter), stdio entrypoint (`npm run mcp` → src/mcp/stdio.ts, key `SENTINEL_API_KEY` env) + Streamable HTTP en `/mcp` (gated AGENT_ENABLED), auth Bearer `sk-sentinel-*` SHA-256 timing-safe, scopes read/trade (read oculta place_order), rate limits 30/min + 5/min trade.
- **`routes/`** — auth (JWT+Google OAuth), portfolio (+snapshot sync), quotes (panel con búsqueda server-side ?q=), rates (dolarapi.com cache 60s → `services/rates.ts`), operations, reports, analysis, agent (SSE chat + sesiones), api-keys, accounts, connections, profile.
